# Voxtral-STT-plugin-for-Covas-next (Made with Mistral Vibe)
Use Voxtral from Mistral AI as STT

1: create a folder named **MistralVoxtralSTT** in %appdata%\com.covas-next.ui\plugins<br>
2: paste the files in this folder<br><br>
In Covas:next, go to plugin tab, it must appear under EdCopilot<br><br>
![image](https://github.com/neoruinc/Voxtral-STT-plugin-for-Covas-next/blob/main/covas_plugin.png)<br><br>
Next, in advanced tab, choose plugin as STT/Microphone Settings<br><br>

![image](https://github.com/neoruinc/Voxtral-STT-plugin-for-Covas-next/blob/main/stt_settings.png)<br><br>

Enjoy!
